### Setcover

#### Лучший результат 5 5 5 5 5 3

Реализовал жадный алгоритм + имитацию отжига (simulated annealing).
Жадная инициализация выбирает множества по наименьшему отношению стоимости к числу новых покрытых элементов. Затем отжиг пытается улучшить решение: на каждом шаге случайно добавляю, удаляю или заменяю множества, после чего чиню покрытие и убираю избыточные множества. Если ход ухудшает решение, принимаю с вероятностью exp(-delta / T). Температура убывает геометрически, при застревании сбрасывается.

### Моя формулировка

Ищу подмножество множеств минимальной суммарной стоимости, покрывающее все элементы. Решение храню как список индексов выбранных множеств.
На каждом шаге SA случайно выбираю одну из четырёх мутаций: добавить случайное множество, удалить случайное множество, заменить одно множество на другое, или заменить k множеств на k случайных. После мутации вызываю repair (дочиню покрытие жадно) и trim (убираю лишние множества, начиная с самых дорогих).


### Описание экспериментов

1. Начал с жадного алгоритма + reverse-delete. Жадник набирает множества по наименьшему отношению стоимости к числу новых покрытых элементов, а reverse-delete проходит по решению от самого дорогого множества и убирает те, чьи элементы полностью покрыты остальными. Это даёт неплохое начальное приближение, но не проходит вторые пороги.
2. Добавил SA с 4 типами мутаций: add (30%), remove (20%), swap (20%), k-swap (30%). Параметры: T0=1000, alpha=0.999 для малых m, alpha=0.9995 для m>5000. Это сильно улучшило результаты на всех тестах.
3. Сделал multistart — 3 запуска SA, каждый стартует от лучшего найденного решения. Время делится поровну между запусками.
4. Добавил рестарт температуры при застревании (1000 шагов без улучшения → T сбрасывается на T0*0.5).
