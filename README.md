### Отчет

#### Лучший результат 5 5 5 5 5 5
Для начала решил реализовать алгоритмы с лекции, пробить легкие тесты.
Реализованы жадники, менял в них направление обхода вершин: по возрастанию степени, по убыванию степени. Работают за O(nlogn+m).

Также реализовал DSatur, работает за O(n^2+m). Теперь у алгоритма есть динамический шаг, берём вершину с наибольшим числом различных цветов среди уже окрашенных соседей. Валит тесты на n>1000.
