### Моя формулировка

Дано n предметов с весами и стоимостями, рюкзак вместимости W. Нужно выбрать подмножество предметов максимальной суммарной стоимости, не превышая вместимость.

### Подходы

**1. DP по весу** — динамика по весу, берётся при W < 200000. Перебираю предметы, для каждого обновляю массив справа налево.

**2. Branch and Bound** — ветвление, отсечение по upper bound от дробного рюкзака при W >= 200000. На каждом узле дерева решаю: взять предмет или пропустить. Верхняя оценка считается через дробный рюкзак на оставшихся предметах. Если оценка не лучше текущего рекорда — ветка отсекается. 

**3. Локальный поиск** — жадная инициализация по плотности, затем итеративное улучшение через swap-окрестности:
- **2-out-1-in**: убираю 2 взятых предмета, добавляю 1 свободный. Если суммарная стоимость растёт — принимаю ход.
- **1-out-2-in**: убираю 1 взятый предмет, добавляю 2 свободных. Аналогично.
